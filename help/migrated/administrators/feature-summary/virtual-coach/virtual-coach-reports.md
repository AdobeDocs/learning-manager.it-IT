# Report degli allenatori virtuali

In qualità di amministratore, puoi visualizzare due report relativi a Virtual Coach. Si tratta di **Riepilogo sull’utilizzo degli Allievi** e di **Dettagli della sessione**.

![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report1.png)

## Riepilogo utilizzo Allievo

Il Riepilogo utilizzo Allievi contiene i dettagli di utilizzo mensili di tutti gli Allievi iscritti all’account. Questi dettagli sull’utilizzo contengono informazioni dettagliate sull’utilizzo e sui modelli di apprendimento.

### Genera riepilogo utilizzo Allievi

Per generare un riepilogo dell’utilizzo degli Allievi:

1. Accedi come amministratore.
2. Passa a **Gestisci** > **Report** > **Report IA**.
3. Nella sezione **Allenatore virtuale**, seleziona **Riepilogo utilizzo Allievi**. Viene visualizzato il popup **Dati sull&#39;utilizzo degli allievi dell&#39;istruttore virtuale**.
4. Selezionare **Data inizio** e **Data fine**.
5. Seleziona **Procedi**. Il report viene generato come file CSV. Il file .csv scaricato è disponibile nella cartella **Download** di Esplora file.

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report2.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-learn-usage-6.png)

## Dettagli della sessione

Il report **Dettagli della sessione** contiene i dettagli della sessione di tutti gli Allievi iscritti all’account negli ultimi 90 giorni. Questi dettagli sull’utilizzo contengono informazioni dettagliate sull’utilizzo e sui modelli di apprendimento.

### Genera dettagli sessione

Per generare un report Dettagli sessione:

1. Accedi come amministratore.
1. Passa a **Gestisci** > **Report** > **Report IA**.
1. Nella sezione **Allenatore virtuale**, seleziona **Dettagli della sessione**. Viene visualizzato il popup **Generazione della richiesta di report**.
1. Seleziona **OK**. Il report viene generato come file CSV. Il file .csv scaricato è disponibile nella cartella **Download** di Esplora file.

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report3.png)

   ![](/help/migrated/administrators/feature-summary/assets/virtual-coach-report-session-4.png)

>[!NOTE]
>
>Adobe Learning Manager non conserverà un record della sessione di Allenamento virtuale di un Allievo. Un Allievo può seguire più sessioni. Tuttavia, all’Allievo non è consentito tornare a una sessione di Virtual Coach precedente.
