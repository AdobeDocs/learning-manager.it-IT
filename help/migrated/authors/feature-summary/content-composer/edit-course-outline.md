# Modificare la struttura del corso

![](../assets/10_outline_tab_generated_lessons_topics_updated.png)

Adobe Learning Manager Content Composer genera una struttura di lezioni e argomenti a partire dal file breve e dal file di origine. Il contorno viene visualizzato nell’area di lavoro in cui sono mostrate tutte le lezioni e i relativi argomenti.

**Nota:** la modifica del profilo è attualmente a livello di conversazione nella versione beta. Non è possibile selezionare una lezione o un argomento nell&#39;area di lavoro per rinominarlo o riordinarlo. Digita la modifica come richiesta in una lingua semplice nel pannello Chat.

L&#39;assistente lavora conversando. Puoi formulare le richieste con parole tue. Di seguito sono riportati alcuni esempi di ciò che è possibile fare:

| **Azione** | **Esempio di richiesta** |
|--------------------------|---------------------------------------------------------------------------|
| Rinominare una lezione o un argomento | &quot;Rinominare la lezione 1 in &#39;Funzionamento del phishing&#39;&quot; |
| Aggiungere una lezione o un argomento | &quot;Aggiungere un argomento alla lezione 2 sul codice QR&quot; |
| Eliminare una lezione o un argomento | &quot;Rimuovi argomento 1.3&quot; |
| Dividere una lezione | &quot;Dividi la lezione 3 in due. Uno per i filtri antispam, uno per la gestione delle patch&quot; |
| Unire le lezioni | &quot;Unire le lezioni 3 e 4 in un&#39;unica lezione&quot; |
| Rigenera il contorno | &quot;Rigenerazione con maggiore attenzione all&#39;igiene delle password&quot; |

Utilizza le richieste in linguaggio semplice nel pannello Chat per modificare lezioni, argomenti o la struttura completa.

La struttura gerarchica è impostata su Lezioni > Argomenti. Non è possibile creare sottoargomenti o strutture a tre livelli.

Quando la struttura è corretta, seleziona **Genera corso** nella barra degli strumenti superiore.
