# Esportare un tema

Esportate un tema come File JSON per personalizzarlo al di fuori di Composizione contenuto o condividetelo con altri autori.

1. Seleziona **Temi** dalla barra degli strumenti per aprire il pannello **Temi del corso**.

2. Passa il mouse sul tema da esportare e seleziona l&#39;icona **Esporta**.
   ![](../assets/47_export_theme_save_as_json_dialog_updated.png)

3. Nella finestra di dialogo visualizzata, scegli un percorso e immetti un **Nome file.**
