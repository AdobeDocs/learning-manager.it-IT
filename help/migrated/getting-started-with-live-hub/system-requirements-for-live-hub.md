# Requisiti di sistema

Utilizza i seguenti requisiti di sistema per configurare ed eseguire le sessioni di Live Hub in Adobe Learning Manager. Live Hub utilizza gli stessi requisiti di browser, sistema operativo e hardware dell’ambiente aula virtuale in cui viene eseguito.

Live Hub è disponibile all’interno delle sessioni di Virtual Classroom e non richiede un’installazione client separata.

| Categoria | Requisiti |
|---|---|
| **Browser per desktop** | Versioni più recenti di Google Chrome, Mozilla Firefox, Microsoft Edge e Safari |
| **Browser per dispositivi mobili** | Chrome Mobile, Safari Mobile e Samsung Internet |
| **Sistemi operativi** | Windows 10 o versioni successive, macOS 15 o versioni successive |
| **Risoluzione schermo** | 1920 × 1080, 1366 × 768, 768 × 1024 (tablet) e 375 × 667 (dispositivi mobili) |
| **Hardware di Windows** | Minimo 8 GB di RAM, processore 8-core, Intel® Core™ i5 o superiore |
| **Hardware Mac** | Minimo 16 GB di RAM, processore a 4 core, 3,2 GHz o superiore |
| **Rete** | Connessione stabile a banda larga con almeno 5 Mbps consigliata per le funzionalità Live Hub basate su audio, video e intelligenza artificiale |

>[!NOTE]
>
>I browser Linux, i dispositivi Chromebook, Firefox Mobile, Opera (desktop e mobile), Internet Explorer 11 e le versioni precedenti del browser non sono supportati.
